Chapter 3

Backprop, one operation at a time

In chapter 1, one click on Backward gave every weight its gradient. This chapter opens up that click. Inside, it is nothing more than multiplying small numbers, one operation at a time.

Skip to the playground ↓ or read the introduction below

What this is

This film follows backpropagation through a single neuron, like chapter 2's but with a bias, one operation at a time. The rest of the page explains each step, then hands you the controls.

Chapter 1 showed what training does: guess, measure, adjust. Chapter 2 showed what the adjusting needs: one slope per weight, together called the gradient, which points uphill on the loss landscape so training can step the other way. In chapter 1 the Backward stage produced every one of those slopes at once. This chapter shows how. If you skipped the earlier chapters, the film and the next section are enough to follow along.

The question

A gradient answers one question: if I nudge this parameter up a little, how much does the loss change? (A network's parameters are its weights and biases; chapter 1's network has 17.) There is an obvious way to find out. Nudge the parameter, run the network again, and measure. That works, and the playground below uses it to double-check every answer. But it costs one extra run of the network for every single parameter, or two if you nudge both ways as the playground does.

Backpropagation gets every gradient for about the cost of three runs, however many parameters there are: one forward pass, then a backward pass that costs about two more. That one trick, more than any other, is why large networks can be trained at all. It is built from three simple tools.

Tool 1: the slope of one operation

Chapter 2 measured slopes by nudging the whole network. Backpropagation instead uses the slope of each small operation, which is always easy to know. Start with one operation on its own, such as tanh. Its slope at a point says how much the output moves when you nudge the input. A slope of 0.5 means a nudge of 0.01 in the input moves the output by about 0.005. Drag across the curve to see the slope change.

Every operation in a network has a simple slope rule. These six cover everything on this page:

OperationSlopeIn words
a + b1 and 1A nudge to either input passes straight through.
a × bb and aEach input's slope is the other input.
tanh(a)1 − tanh(a)²Steep near 0, flat far away.
σ(a)σ(a)·(1 − σ(a))Steepest at a = 0, where σ = 0.5; flat when σ is near 0 or 1.
−log(a)−1 / aVery steep when a is close to 0.
a²2aGrows with a; zero at a = 0.

These are called local slopes, because each one looks only at its own inputs and output, and nothing else in the network.

Tool 2: the chain rule

Operations come in chains. If y moves 3 times as much as x, and z moves 0.5 times as much as y, then z moves 3 × 0.5 = 1.5 times as much as x. Slopes along a chain multiply, the same way exchange rates do: if 1 yen buys 0.007 dollars and 1 dollar buys 0.9 euros, then 1 yen buys 0.007 × 0.9 euros.

That is the whole chain rule. Backpropagation applies it to every path through the network at once, and reuses shared work, so nothing is computed twice.

Tool 3: the graph, three rules, and a tape

Any calculation can be drawn as a graph: numbers flow along wires into small operations. The film's neuron is six operations. Chapter 1's network, for a single dot, is about thirty. Backpropagation walks that graph backward with three rules:

  1. Start with 1 at the loss. Nudge L by a little and L changes by exactly that much, so ∂L/∂L = 1.
  2. Multiply and pass back. Each operation takes the gradient it has received, multiplies it by its local slope for each input, and sends the result to that input.
  3. Add what arrives. If a value is used in several places, its gradient is the sum of everything that comes back to it.

To walk backward you need to know the order things happened in. So during the forward pass, every operation writes itself onto a list called the tape. The backward pass reads the tape in reverse. How to read the figure

Boxes
Starting numbers. A solid box is a weight the network learns. A dashed box is an input, which gets a gradient too but is never changed by training.
Circles
Operations. The number under each circle is its result from the forward pass.
Gradient tags
The colored tag above a node is its gradient, ∂L/∂(that node): blue for a positive gradient, orange for a negative one. (Chapter 1's backward view colors the direction each weight should move, which is the opposite sign.)
Slope tags
“×0.20” on a wire is the local slope the backward pass multiplies by when it sends a gradient back along that wire.
Moving dots
Forward, values flow to the right. Backward, gradients flow to the left.
The tape
The table under the graph: every operation in the order it ran. The forward pass fills it top to bottom; the backward pass works up from the bottom.

Things to try

  • In One value, two uses, step until h gets its first gradient, then step once more. The second contribution is added to the first instead of replacing it. If it replaced it, h would end up with 2.400 instead of 1.600; the nudge test measures 1.600.
  • In One neuron, finish the backward pass, then drag w₁. Every gradient updates as you drag.
  • Raise b (or w₁) until z is large and positive, so the neuron is confident and right. The gradients shrink toward zero: there is nothing to fix.
  • Lower b until z is far below zero instead. ŷ gets close to 0 and −log gets very steep, but σ flattens just as fast, so the two cancel: ∂L/∂z = ŷ − 1 approaches −1, its largest size. A confident wrong answer pushes hardest, but never harder than that.
  • Multiply the slopes of −log and σ by hand: (−1/ŷ) × ŷ(1 − ŷ) = ŷ − 1. For an orange dot (y = 0) the loss is −log(1 − ŷ), and the same steps give ŷ − 0. In both cases the slope is ŷ − y, which is why chapters 1 and 2 could fuse σ and the loss into a single operation.
  • In the Warm-up, set a to 2, so that d = 2 × (−2) + 4 = 0. Then f's gradient is 0: when d is 0, nudging f changes nothing.

What runs where

Everything runs in this page's JavaScript on your CPU, in 64-bit floats. The playground builds every graph with the code shown above. The Python shown beside it is a line-by-line translation of the same program, and the PyTorch example computes the playground's neuron with a real library. Its Step button runs backward() one tape entry per click, after a first click that sets ∂L/∂L = 1. The nudge test compares the real backward() with a measured slope, (L(x + ε) − L(x − ε)) / 2ε with ε = 0.0001.
